# Security and privacy

Please do not open public issues containing private reports, screenshots, source figures, absolute paths, credentials, or sensitive visual evidence.

This plugin is designed to be read-only with respect to the audited target. It writes audit artifacts to a separate run directory and does not publish user assets. Native Codex subagents operate under the host environment's permissions and data policies; review those policies before auditing sensitive material.

For a security or privacy concern, contact the future repository maintainer privately after a public repository contact address has been configured. Until then, do not disclose sensitive details in a public issue.
